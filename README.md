# AMO-QIS Lab PID Circuit Analysis and More

Analysis notes and reference materials for understanding the AMO-QIS Lab PID v3.9 circuit, including schematic-level review, PCB/NIM-box context, and supporting op-amp configuration references.

## Contents

- `PID_Circuit_Detailed_Analysis.md`  
  Earlier detailed notes on the PID circuit schematic and functional blocks.

- `PID_v3_9_Circuit_Report.md`  
  Main report for understanding the PID v3.9 circuit, including PID theory, schematic analysis, board-level mapping, and NIM-box observations.

- `Op_Amp_Amplifier_Configurations.md`  
  General reference notes on classic op-amp amplifier configurations, with equations, analysis, applications, and design comments.

- `Op_Amp_Amplifier_Configurations_Online_Diagrams.md`  
  Source-linked op-amp configuration reference using locally stored white-background images for readable GitHub preview.

- `PID_GDrive/pid39sch01.png` and `PID_GDrive/pid39sch02.png`  
  PID v3.9 schematic screenshot images used by the report.

## Image Assets

- `assets/op_amp_configurations/` contains transparent-background source images.
- `assets/op_amp_configurations_white/` contains white-background versions used for GitHub Markdown preview.

## Purpose

The goal of this repository is to collect and organize enough circuit-level context to fully understand the PID v3.9 implementation: how the PID theory maps onto op-amp circuit blocks, how those blocks appear in the schematic, and how the schematic relates to the physical board and external NIM-box connections.

## Notes

These documents are working research notes. Source pages are cited inside the relevant Markdown files where external figures or references are used.
